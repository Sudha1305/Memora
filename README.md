# MEMORA

### Every Frame Holds a Story.

MEMORA is a family memory and photo archive website designed to preserve family photographs, memories, relationships, and special moments in one beautiful digital space.

## Features

1. Cinematic landing page
2. Family tree
3. Memories and photo gallery
4. Search and category filtering
5. Favorite memories
6. Photo upload
7. Recycle bin and restore
8. Collage creator
9. Time Capsule
10. Lightbox photo viewer
11. Responsive design
12. Theme switching

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript
4. HTML Canvas API
5. LocalStorage API
6. FileReader API
7. Google Fonts

## Project Purpose

MEMORA brings family photographs and memories together in an interactive digital archive, making it easier to preserve and revisit meaningful moments.
