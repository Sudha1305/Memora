# MEMORA

Every Frame Holds a Story. MEMORA is a family memory and photo archive website designed to preserve family photographs, memories, relationships, and special moments in one beautiful digital space.

## 🔗 Live Demo
You can view the live project here: [Live Demo](https://sudha1305.github.io/Memora/)

## Features
* Cinematic landing page
* Family tree
* Memories and photo gallery
* Search and category filtering
* Favorite memories
* Photo upload
* Recycle bin and restore
* Collage creator
* Time Capsule
* Lightbox photo viewer
* Responsive design
* Theme switching

## Technologies Used
* HTML5
* CSS3
* JavaScript
* HTML Canvas API
* LocalStorage API
* FileReader API
* Google Fonts

## Project Purpose
MEMORA was built to bridge the gap between traditional family photo albums and modern web technology. By leveraging local browser storage and canvas manipulation, it provides a private, secure, and highly interactive diary-style archive for families to protect their heritage for generations to come.
